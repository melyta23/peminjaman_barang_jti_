Peran & Tanggung Jawab Setiap Aktor
Tiga aktor utama yang terlibat dalam sistem SIPEMBAR JTI beserta aktivitasnya.

🎓 Mahasiswa

  • Registrasi akun baru
  • Login ke sistem
  • Melihat katalog sarpras lab
  • Mengisi & mengajukan form peminjaman
  • Memantau status permohonan
  • Menerima & menggunakan barang
  • Mengembalikan barang tepat waktu
  • Mencetak surat peminjaman

🛡 Admin / Laboran JTI

  • Memantau dashboard real-time
  • Menerima notifikasi permohonan baru
  • Memeriksa & memverifikasi data peminjam
  • Menyetujui atau menolak permohonan
  • Menyerahkan barang yang disetujui
  • Menambah catatan admin
  • Memeriksa kondisi barang saat dikembalikan
  • Menandai peminjaman sebagai Selesai
  • Mengelola inventaris sarpras

⚙️ Sistem / Database

  • Validasi form & autentikasi
  • Generate kode transaksi unik (JTI-XXXXXX-YYYY)
  • Menyimpan permohonan ke database
  • Update stok_tersedia saat disetujui
  • Restore stok saat selesai / ditolak
  • Validasi ketersediaan stok real-time
  • Menampilkan status & riwayat peminjaman

Referensi Status Peminjaman
Empat status yang berlaku dalam sistem beserta aksi yang diperlukan dan efek pada stok inventaris.
Status Ditetapkan Oleh Kondisi / Trigger Efek pada Stok Aksi Selanjutnya
⏳ MENUNGGU Sistem (otomatis) Mahasiswa submit form peminjaman Tidak berubah — stok belum dikurangi Admin review & buat keputusan
✅ DISETUJUI Admin / Laboran JTI Admin klik "Setujui" & stok mencukupi stok_tersedia − jumlah (barang keluar) Admin serahkan barang → Mahasiswa gunakan → Kembalikan → Admin selesaikan
❌ DITOLAK Admin / Laboran JTI Admin klik "Tolak" (barang rusak/jadwal bentrok/dll) Tidak berubah (atau dikembalikan jika dari Disetujui) Mahasiswa dapat notifikasi & catatan alasan penolakan
🏁 SELESAI Admin / Laboran JTI Admin klik "Selesai" setelah barang dikembalikan & dicek stok_tersedia + jumlah (barang masuk kembali) Peminjaman selesai — tercatat di riwayat
